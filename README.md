# おえかきリレー

1台のタブレットをみんなで回して遊ぶ、アイスブレイク・レクリエーション用のお絵描きリレーWebアプリ。

## いまの状態

v0.4：3モードすべて遊べる

- A　おえかきリレー：絵をおぼえて、まっしろな紙にかいてつなぐ。最後の人がお題を当てる
- B　えとことばリレー：絵→ことば→絵…と交互につなぐ（ガーティックフォン方式）
- C　おえかきバトンパス：お題を知っている人が1まいの絵にかきたす。前の人の線は消せない。最後の人が当てる
- じゅんび：3〜10人・名前、お題（かんたん＝ひらがな名詞約210語／むずかしい＝修飾語約150語×名詞の自動生成／じぶんで）、タイマー（なし・15・30・45・60びょう、0になると自動で次の人へ）
- 結果発表：「じゅんばんにみる／ぎゃくからみる」→ ためてから1まいずつ発表 → さいごに答えあわせ
- いちらん：お題から最後まで、矢印つきで1画面にならべる（りれきからも見られる）
- りれき：ゲーム終了時に自動保存、最新5しあい
- キャンバス：ペン・けしゴム・バケツ、もどす・すすむ・ぜんけし、シンプル12色／プロ48色、太さ3段階、ペンだけ・ひつあつ・おと

## 使い方

`index.html` をブラウザで開くだけで動く（1ファイル、インストール不要）。
フォントはGoogle Fontsから読み込む。読み込めない環境では端末のフォントで表示される。
