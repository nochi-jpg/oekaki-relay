# おえかきリレー

1台のタブレットをみんなで回して遊ぶ、アイスブレイク・レクリエーション用のお絵描きリレーWebアプリ。

## いまの状態

v0.1：キャンバスだけの試作（書き味の確認用）

- ペン・けしゴム・12色・太さ3段階
- もどす／すすむ／ぜんけし（ぜんけしも「もどす」で戻せる）
- ペンの筆圧に対応（オン・オフ可）
- 「ペンだけ」モード：指や手のひらでは描けなくする
- 描いている途中にほかの指が触れても無視する
- ほぞんテスト：履歴保存用に縮小した画像の大きさを表示する
- ボタンの押しこみ感と効果音（WebAudioで合成、オン・オフ可）

## 予定しているモード

- A　お絵描きリレー（絵→絵→絵→最後の人が答える）
- B　絵と文字のリレー（絵→文字→絵→文字…、ガーティックフォン方式）
- C　お絵描きバトンパス（お題を知っている人が15秒ずつ描き足し、最後の人が答える）

共通：3〜10人、名前入力、お題はランダムか自分で決める、リザルトで順番に見る、過去5試合を端末に保存する

## 使い方

`index.html` をブラウザで開くだけで動く（1ファイル、インストール不要）。
フォントはGoogle Fontsから読み込む。読み込めない環境では端末のフォントで表示される。
