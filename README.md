# おえかきリレー

1台のタブレットをみんなで回して遊ぶ、アイスブレイク・レクリエーション用のお絵描きリレーWebアプリ。

## いまの状態

v0.2：キャンバスだけの試作（書き味の確認用）

- どうぐ：ペン・けしゴム・バケツ（塗りつぶし）
- そうさ：もどす・すすむ・ぜんけし（ぜんけしも「もどす」で戻せる）
- せってい：ペンだけ（指や手のひらでは描けなくする）・ひつあつ・おと
- いろ：「シンプル」12色／「プロ」48色（8色の系統×明るさ6段）をスイッチで切りかえ
- 太さ3段階、描いている途中にほかの指が触れても無視する
- ボタンの押しこみ感と効果音（WebAudioで合成）
- タイトルロゴ（assets/logo.png。index.html には縮小版を埋めこみ済みなので、1ファイルで動く）

## 予定しているモード

- A　お絵描きリレー（絵→絵→絵→最後の人が答える）
- B　絵と文字のリレー（絵→文字→絵→文字…、ガーティックフォン方式）
- C　お絵描きバトンパス（お題を知っている人が15秒ずつ描き足し、最後の人が答える）

共通：3〜10人、名前入力、お題はランダムか自分で決める、リザルトで順番に見る、ゲーム終了時に自動で過去5試合ぶんを端末に保存する（保存ボタンはなし）

## 使い方

`index.html` をブラウザで開くだけで動く（1ファイル、インストール不要）。
フォントはGoogle Fontsから読み込む。読み込めない環境では端末のフォントで表示される。
